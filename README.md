# Student Grade Calculator

A simple, responsive web app that helps students calculate their grades based on assignment scores, total points, and weights. Includes final percentage, weighted score, letter grade, and a dark mode toggle for easy viewing.
## Features

- Add multiple assignments with scores, total points, and weight percentages.
- Calculates **raw percentage**, **weighted percentage**, and **letter grade**.
- Mobile-responsive and clean design.
- Dark mode toggle that persists across pages.
- Summary table showing each assignment's contribution and percentage.
- Home page linking to the calculator (ready for future projects).

## How to Use

1. Open `index.html` in a browser.
2. Click **Student Grade Calculator** to open the calculator page.
3. Add assignments by entering **score**, **total points**, and **weight**.
4. Click **Calculate Grade** to see:
   - Final raw percentage
   - Weighted percentage
   - Letter grade (A*, A, B, C, D, F)
5. Use **Clear All** to reset, or **Toggle Dark Mode** for dark theme.
